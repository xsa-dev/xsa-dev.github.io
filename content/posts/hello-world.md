Этот блог построен на базе **[Zola](https://www.getzola.org/)** — быстрого статического генератора сайтов на Rust.

## Преимущества Zola

1. **Один бинарник:** Никаких `node_modules`, Ruby gems или Python venv.
2. **Высокая производительность:** Сборка сотен страниц занимает доли секунды.
3. **Шаблонизатор Tera:** Мощный синтаксис, вдохновленный Jinja2 / Liquid.
4. **Встроенная подсветка синтаксиса:** Быстрая подсветка кода без клиентского JS.

### Пример кода на Rust

```rust
fn main() {
    println!("Hello, Zola!");
}
```
